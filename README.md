# VISCU-VIC Landing Page

Modern industrial landing page created for the Czech insulation company VISCU-VIC.

## 🚀 Project Overview

This website was built using:

* HTML5
* CSS3
* Vanilla JavaScript
* AI-assisted development

The project represents a responsive business landing page for a technical insulation company operating in the Czech Republic.

---

## 🎯 Features

* Responsive modern design
* Industrial engineering style
* Project gallery carousel
* Contact section
* Services presentation
* Materials overview
* Smooth scrolling navigation
* Mobile-friendly layout
