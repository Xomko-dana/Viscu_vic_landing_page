## Image Sources

You can source industrial images from:

1. **Your own projects** (best option for authenticity)
2. **Unsplash.com** - Search for:
   - "industrial pipes"
   - "hvac system"
   - "ventilation"
   - "factory interior"
   - "mechanical room"
   - "industrial insulation"

3. **Pexels.com** - Similar keywords

4. **Pixabay.com** - Free industrial images

## Image Optimization

Before adding images to this folder, optimize them:

1. **Online tools:**
   - TinyPNG.com
   - Squoosh.app
   - ImageOptim (Mac)

2. **Target file sizes:**
   - Hero image: 300-800KB
   - Project images: 200-500KB each

3. **Formats:**
   - WebP (best compression, modern browsers)
   - JPEG (universal support)
   - Avoid PNG for photos (larger file sizes)
